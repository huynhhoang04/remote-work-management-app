## 2. Lỗi đề xuất mở issue

### MOB-003 — Empty state chat bị lật ngược (P2, ui)

- **Route:** `mobile/src/app/(app)/chat/[id].tsx:354`
- **Môi trường:** Small_Phone 720×1280 @320dpi, Android 14 · debug (Metro)
- **Ảnh:** `qa-review/c3-chat-room.png`, `qa-review/crop-chat-flipped.png`

**Bước tái hiện**
1. Tab **Trò chuyện** → mở hội thoại chưa có tin nhắn (DIRECT "Hoang Van Huynh" hoặc kênh dự án trống).

**Kỳ vọng:** icon + "Chưa có tin nhắn" + dòng gợi ý hiển thị bình thường.
**Thực tế:** cả khối bị mirror dọc — chữ đọc ngược từ dưới lên, icon lật úp.

**Nguyên nhân (đã xác định trong mã nguồn):**
`FlatList inverted` tự bọc `ListEmptyComponent` bằng transform lật
(`@react-native/virtualized-lists/Lists/VirtualizedList.js:2079`:
Android `transform: [{scale: -1}]`). Style của empty state lại lật thêm lần nữa:

```tsx
// chat/[id].tsx:354
empty: { … transform: [{ scaleY: -1 }] },
```

Hai lần lật ⇒ hiển thị ngược.

**Hướng fix:** bỏ `transform: [{ scaleY: -1 }]` khỏi `styles.empty`.

## 4. Vướng mắc môi trường

1. **Tablet Samsung SM-X110** (`R83Y203JV4Y`) — 800×1340 @213dpi, arm64, Android 14.
   Đã build APK `arm64-v8a` và cài được, nhưng sau đó **rơi khỏi `adb devices`** (lsusb vẫn thấy
   thiết bị ở MTP mode). Cần trên tablet: mở khoá, chấp nhận lại "Allow USB debugging".
   Nếu vẫn không lên: thêm udev rule rồi `adb kill-server && adb start-server`:
   ```
   SUBSYSTEM=="usb", ATTR{idVendor}=="04e8", MODE="0666", GROUP="plugdev"
   ```
   Tài khoản hiện tại **không thuộc nhóm `plugdev`** — có thể là nguyên nhân (ACL USB đã cho
   user quyền đọc/ghi nên chưa chắc).
2. **Bản sửa Supabase chưa lên Render.** Cần commit + push `main` (hoặc chạy job deploy) để
   backend mới ghi log `HTTP <status> <body>`; sau đó đọc log Render để biết nguyên nhân thật.
   Secret `RENDER_DEPLOY_HOOK_URL` đã có, workflow dùng đúng tên biến.
